# AI学情收集系统

## 🎯 项目简介
一套基于Deepseek API的AI对话式学生每日学情收集系统，采用对话式交互，自动收集、整理和汇总教师填报的学情数据。

## ✨ 核心特性
- 🤖 **AI对话交互**：自然语言对话，零学习成本
- 📊 **自动数据提取**：AI自动识别关键信息
- 📈 **Excel自动生成**：自动生成标准Excel报表
- 🏠 **本地部署**：支持局域网部署，数据本地存储
- 🔒 **数据安全**：所有数据存储在本地服务器

## 🛠️ 技术栈
- **前端**：HTML5 + CSS3 + JavaScript
- **后端**：Node.js + Express
- **AI服务**：Deepseek API
- **数据处理**：ExcelJS
- **部署**：PM2进程管理

## 🚀 快速开始

### 1. 环境要求
- Node.js 16.0+
- 至少2GB内存
- 局域网环境

### 2. 安装步骤
```bash
# 进入项目目录
cd AI学情收集系统

# 安装依赖
npm install

# 启动服务（也可直接双击 start.bat）
npm start
```

### 3. 访问系统
打开浏览器访问：`http://服务器IP:3000`

### 4. Windows 一键启动（推荐）

**双击 `start.bat`** 即可。脚本会依次完成：

1. 检查 Node.js 是否安装、版本是否满足要求
2. 首次运行时自动安装依赖
3. 检测 3000 端口是否被占用，若被占用则自动释放
4. 启动服务并自动打开浏览器

启动后窗口会同时显示本机地址和局域网地址（例如 `http://192.168.2.16:3000`），
局域网内的其他电脑用后者即可访问。关闭该窗口或双击 `stop.bat` 停止服务。

> 若提示「无法自动释放端口」，说明该端口被其他程序占用或权限不足，
> 请右键选择「以管理员身份运行」。

## 🤖 两种运行模式

- **AI对话模式（推荐）**：编辑 `config.js` 或设置环境变量 `DEEPSEEK_API_KEY`，填入 Deepseek API Key，即可使用自然语言对话式填报。
- **本地规则模式**：未配置 API Key 时系统自动回退为本地关键词提取，无需联网也能完成填报、汇总和 Excel 生成，适合先试用。

切换模式只需配置/移除 API Key，无需重启依赖。

### API Key 设置
点击侧边栏「API设置」，填入 DeepSeek API Key 并保存即可热切换为 AI 对话模式，无需重启服务；清除 Key 后自动回到本地规则模式。

## 🧑‍🎓 学生情况数据
系统自动读取项目根目录的《初一学生情况汇总表.xlsx》，在「学生情况」中实时预览留守儿童、身体特殊生、心理特殊生、问题学生、逃学厌学名单和汇总表，支持手动刷新与自动更新。
支持直接在页面导入新的 xlsx（以《初一学生情况汇总表》为模板），并支持跨分类搜索学生姓名、班级、联系电话。

## 📊 每日报表
生成的每日 Excel 除学情汇总外，还包含与学生汇总表格式一致的「学生情况汇总」及各分类 Sheet。

## 📋 使用流程
1. 教师在浏览器中打开系统界面
2. AI助手以对话方式引导填写学情信息
3. AI自动提取关键信息
4. 系统自动生成Excel汇总报表
5. 教务可下载和管理所有数据

## 📊 数据字段
- 日期、班级、学科、教师
- 出勤情况、缺勤原因
- 课堂表现、作业完成情况
- 需关注事项
